# Glossary

The words the interface uses for its main ideas, so every message says the same thing the same
way. Portuguese is European Portuguese (pt-PT).

| English | Português | Notes |
|---|---|---|
| household | família (as famílias) | Not "agregado", which reads like a tax form. |
| settlement | acerto | Verb: "acertar contas"; the money sent is a "transferência". |
| balance | saldo | |
| bill | fatura | |
| split | divisão | Verb: "dividir"; "percentagem", never "porcentagem". |
| rule | regra de divisão | |
| category | categoria | |
| upkeep | manutenção | e.g. "manutenção do caminho". |
| paid by | pago por | As a question: "Quem pagou". |
| owes | deve | "A deve 20 € a B": the euro sign after the number, with a space. |

Prefer European forms over Brazilian ones: partilhar, utilizador, ecrã, ficheiro, eliminar,
registar, contacto, equipa; "está a carregar" rather than "carregando".
